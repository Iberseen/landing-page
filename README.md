# Landing Page · Fokus

Landing page responsive para un producto ficticio (app de planificación semanal). Proyecto para practicar maquetación moderna sin frameworks.

## Qué incluye

- HTML semántico y enlace "Saltar al contenido"
- Diseño mobile first con CSS Grid y Flexbox
- Tipografía fluida con `clamp()`
- Sección de precios, FAQ con `<details>` y cabecera fija
- Respeta `prefers-reduced-motion`
- Foco visible y contraste suficiente

## Estructura

```
index.html
css/styles.css
```

## Uso

Abre `index.html` en el navegador. No necesita instalación.
